# Dead ends

The brief asks for these to be specific: the source, what was expected, and the exact reason it failed. "Scraping is unreliable" does not count.

## Template

```
## Source name (hypothesis ID)

Expected:        what I thought it would give me
What I ran:      steps or command, and on how many companies
What came back:  the numbers
Why it failed:   the precise reason
Evidence:        path in evidence/
Could it work with more resources?  yes / no / partly, and what it would take
```
