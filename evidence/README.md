# Evidence

Raw outputs behind the claims in the main document. If a number appears in the README, a file here should show where it came from.

Rules:

1. Save the output as it came back (JSON response, HTML page, screenshot, CSV). Do not clean it up.
2. Name files `YYYY-MM-DD_source_what.ext`, for example `2026-11-12_hmrc_manual-check-01.png`.
3. Never edit a file after saving it. A re-run gets a new file.
4. Reference the file from the matching decision-log entry.
5. Before committing someone else's data, check that you are allowed to redistribute it. If not, keep the file locally and commit a note describing it.
